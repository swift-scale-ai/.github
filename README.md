## What I’m building

| Project | What it does | Start here |

### Native Apple Silicon tools

| Project | What it does | Download |
| --- | --- | --- |
| **[ReTop](https://github.com/swiftscalecloud/ReTop)** | A colorful native process and system monitor with per-core CPU, memory, swap, and network views. | [Signed release](https://github.com/swiftscalecloud/ReTop/releases/latest) |
| **[ReMTR](https://github.com/swiftscalecloud/ReMTR)** | A graphical network-path monitor with loss, latency, jitter, route changes, and RTT history. | [Signed release](https://github.com/swiftscalecloud/ReMTR/releases/latest) |
| **[ReDu](https://github.com/swiftscalecloud/ReDu)** | A read-only visual disk-usage analyzer with allocated/logical sizes, tree navigation, and file-type insights. | [Signed release](https://github.com/swiftscalecloud/ReDu/releases/latest) |

All Re* release binaries are built for **Apple Silicon**, signed with an Apple **Developer ID**, notarized, and published with SHA-256 checksums.

## Principles

- **Local first** — source code and filesystem data stay close to the developer.
- **Verifiable automation** — tools should show their work and validate outcomes.
- **Native by default** — focused, fast software designed for Apple Silicon Macs.
- **Safe operations** — read-only defaults, explicit actions, and reproducible releases.
- **Open development** — public roadmaps emerge from issues, pull requests, and working code.
